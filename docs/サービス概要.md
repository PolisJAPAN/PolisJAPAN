# PolisJAPAN サービス概要

PolisJAPAN が何をするサービスか、誰が使うか、どんな機能があるかをまとめる。最初に読む文書である。仕組みは `docs/アーキテクチャ.md` から先を参照。

## 1. サービスの目的

Polis は、インターネットで意見を集め、統計的な分析で合意点を探る「ブロードリスニング」のためのシステムである。参加者は、ほかの人の意見に「賛成」「反対」「パス」で投票する。返信の機能が無いので言い争いにならず、投票の傾向から意見グループが自動で分けられ、グループをまたいで支持される意見が見える。

本家の Polis（pol.is）は、日本の利用者には次の点で使いにくい。

1. 日本語の画面と操作説明が無い
2. PC 向けの画面で、スマートフォンでは使いにくい
3. テーマの一覧や検索が無く、テーマを見つけられない
4. テーマの投稿に手間がかかる

PolisJAPAN は、**Polis を日本で使えるようにする**ためのサービスである。投票と意見グループ化は本家の pol.is をそのまま使い、その周りに次のものを提供する。

- サービスを紹介する LP
- 日本語の画面とチュートリアル
- テーマの一覧、検索、絞り込み、並び替え
- スマートフォンに合わせた画面（ホーム画面に追加できる PWA）
- AI の補助による手軽なテーマ作成
- pol.is の投票データを取得して独自に表示する分析画面

## 3. 利用者と運営者

| 立場 | できること |
| --- | --- |
| 利用者（ログイン不要） | テーマを探す、意見に投票する、意見を投稿する、分析を見る、テーマを作る、テーマを共有する、お気に入りに入れる、運営に問い合わせる |
| 運営者 | 管理画面で下書きを確認・編集・削除する、投稿に失敗した下書きを再投稿する、お知らせを出す、アラームに対応する |

利用者のアカウント機能は無い。お気に入りや入力途中の下書きは、利用者のブラウザの中だけに保存する。投票者の識別は pol.is が行う。

## 4. 機能一覧

| 機能 | 内容 | 詳細 |
| --- | --- | --- |
| LP | サービスの考え方と使い方を紹介し、アプリへ誘導する | `docs/画面仕様書.md` |
| テーマ一覧 | テーマをカードで一覧表示する。カテゴリ絞り込み、キーワード検索、並び替え（更新順・意見順・新着順・古い順・人気順）、お気に入り | `docs/画面仕様書.md` |
| テーマ詳細・投票 | pol.is の投票画面を埋め込み、意見への投票と意見の投稿を行う | `docs/画面仕様書.md` |
| 分析 | 意見ごとの賛成・反対・パスの割合と、意見グループごとの傾向をグラフで表示する。グループをまたいで支持される意見を上に並べる | `docs/画面仕様書.md` |
| テーマ作成 | テーマ、最初の意見、説明、カテゴリを入力して投稿する。AI が対立軸・意見・説明を下書きする「AI アシスト」と、すべて自分で書く「マニュアル」がある | `docs/画面仕様書.md`、`docs/サーバー設計.md` |
| テーマの自動公開 | 投稿されたテーマを、審査を挟まずに pol.is に作成して一覧に載せる（投稿から 15 分程度） | `docs/サーバー設計.md` |
| 投票情報の自動更新 | pol.is から投票数・意見数・集計結果を 5 分ごとに取得し、一覧と分析に反映する | `docs/サーバー設計.md`、`docs/データ仕様.md` |
| 共有 | テーマへのリンクを作る。SNS などでカード表示されるための情報（OGP）を付ける | `docs/API仕様.md` |
| お知らせ | 運営からのお知らせをアプリ内に表示する。未読があれば自動で開く | `docs/クライアント設計.md` |
| お問い合わせ | 運営へのメッセージを送る。運営と送信者にメールが届く | `docs/API仕様.md` |
| 管理画面 | 下書きの一覧、承認（再投稿）、編集、削除 | `docs/画面仕様書.md` |
| 監視 | API の死活、バッチの失敗、投稿の滞留を検知してメールで通知する | `docs/運用手順書.md` |

## 5. 用語

| 用語 | 意味 |
| --- | --- |
| テーマ | 議論の題目。pol.is の「カンバセーション」1 つに対応する |
| 意見 | テーマに対する短い主張。利用者はこれに投票する。pol.is では「コメント」と呼ぶ |
| シード意見 | テーマの作成時に最初から入れておく意見 |
| 投票 | 意見への「賛成」「反対」「パス」 |
| 意見グループ | 投票の傾向が似た参加者の集まり。pol.is が自動で分ける |
| 対立軸 | テーマに対する立場の分かれ方。AI アシストで、シード意見を作る前に生成する |
| `conversation_id` | pol.is がテーマに付ける ID。詳細画面の URL、投票画面の埋め込み、集計 CSV のファイル名に使う |
| `report_id` | pol.is の集計レポートの ID。集計データの取得と、本家の詳細レポートへのリンクに使う |
| 下書き | 利用者が投稿したテーマのデータ。pol.is に作成されるまで DynamoDB に置かれる |
| 承認済み（APPROVED） | 下書きが pol.is への作成を待っている状態。投稿された下書きは最初からこの状態になる |
| 隔離（FAILED） | pol.is への作成に繰り返し失敗し、自動では再試行されなくなった下書きの状態 |
| カテゴリ | テーマの分類。1 社会・政治、2 お金・資産、3 男女・性別、4 外国人問題、5 テクノロジー、6 医療・福祉、7 生活、8 その他 |

## 6. 利用している外部サービス

| サービス | 用途 |
| --- | --- |
| pol.is（本家 Polis） | 投票、意見の投稿、意見グループ化、集計データの提供。PolisJAPAN 用のアカウントでテーマを作成する |
| OpenAI API | AI アシストでの対立軸・意見・説明の生成 |
| LangSmith | AI に渡すプロンプトの管理と、生成の記録 |
| AWS | サイトの配信、API、バッチ、データの保存、メール送信、監視 |
| GitHub / GitHub Actions | ソースコードの管理、本番への自動デプロイ、文書の検査 |

pol.is の画面や API が変わると、投票画面の埋め込み、集計データの取得、テーマの自動作成が影響を受ける。未対応のリスクは `docs/改善バックログ.md` にまとめている。
