## 4. 対応しないもの

### 4.1 pol.is 本体の機能で、当システムからは変えられない

意見の投稿と投票の画面は pol.is の iframe、グループ分けは pol.is のアルゴリズムである。

| 要望（票） | 理由 |
| --- | --- |
| 投稿した意見を取り消したい（46/2） | 意見の投稿は iframe 内 |
| 自分の意見が「賛成」扱いになる（46/0） | pol.is の仕様 |
| 投票をやり直したい（6/1） | iframe 内の投票画面 |
| 意見の表示順を変えたい（7/1） | pol.is のアルゴリズム |
| 一定数回答するまで他人の回答を見せない（39/9） | 同上 |
| 4 択目「テーマと無関係」がほしい（25/5） | iframe 内の投票画面 |
| 極端な意見の 2 人だけでグループができる（33/13） | pol.is のクラスタリング |
| 似た意見を AI でまとめてほしい（13/1） | pol.is 内部のデータが必要 |
